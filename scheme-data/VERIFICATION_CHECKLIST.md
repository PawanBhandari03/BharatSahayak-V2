# Scheme verification checklist

14 of 50 schemes are verified. 36 still need a person to check them. (Generated by `npm run checklist:schemes`; do not edit by hand.)

## How to verify one scheme (about 5 minutes)

1. Open the **official page** (link below) in a browser. The government scheme portal needs a browser; it cannot be read by scripts.
2. Compare **every line** in the block with the page: age, gender, state, work, category, income limit, land, BPL, amount, documents.
3. If anything differs, fix that scheme in `scheme-data/schemes.json` first (use `null` when the page does not say).
4. Run the command in the block. It marks the scheme verified, stores the page you checked and today's date.
5. Run `npm run validate:schemes`, then commit.

Only mark a scheme verified if you really compared it. Verified schemes are the ones shown to citizens in production.
